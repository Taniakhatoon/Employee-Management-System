🏢 Employee Management System
Sujatha Women Degree College

A web-based Employee Management System developed using Flask to manage and maintain employee records digitally.

🚧 Status: Under Development

###📌 Project Overview

This system is designed to help Sujatha Women Degree College manage employee information efficiently through a centralized web application.
It reduces manual paperwork and improves data organization by storing records digitally.

###🛠️ Technologies Used

HTML
CSS
Python
Flask Framework
SQLite Database

###💡 Features

Add new employee records
View employee details
Update employee information
Delete employee records
User-friendly web interface

###🚀 How to Clone and Run This Project on Desktop

Follow the steps below to run this project on your local system.

1️⃣ Prerequisites

Make sure the following are installed:

Python 3.8 or higher
Git
Any code editor (VS Code recommended)

Check versions:

python --version
git --version

2️⃣ Clone the Repository

Open Command Prompt / Terminal and run:
git clone https://github.com/Taniakhatoon/employee-management-system.git
Navigate into the project folder:
cd employee-management-system

3️⃣ Create and Activate Virtual Environment (Optional but Recommended)

Create virtual environment:

python -m venv venv

Activate it:

* Windows
  venv\Scripts\activate

* Mac / Linux
  source venv/bin/activate

4️⃣ Install Dependencies
pip install flask

5️⃣ Run the Application
python app.py

After running the server, open your browser and go to:

http://127.0.0.1:5000/

The Employee Management System will now run on your desktop.
