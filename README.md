# Employee Management System – Sujatha Women Degree College

A web-based Employee Management System developed using Flask, HTML, and CSS.

🚧 Status: Work in Progress (Under Development)

## 📌 Project Overview
This system is being developed to manage employee records digitally for Sujatha Women Degree College. 
The goal is to replace manual record-keeping with a structured web-based solution.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Python
- Flask Framework
- SQLite (if you are using it)

## 💡 Current Features Implemented
- Basic project structure setup
- Employee form design
- Database connection (if done)
- Add employee functionality (if done)

## 🔄 Features In Progress
- Edit & Delete functionality
- Search feature
- UI improvements
- Authentication system

## 🎯 Objective
To build a secure and user-friendly platform for managing staff records efficiently.
